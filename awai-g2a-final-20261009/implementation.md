# AWAI G2-A — 最終比較・調整
2026-10-09。S0黒い膜のみ。Original / Readable × A / B。KASANE・AIMA・本編統合は未着手。美術・触感の承認待ち。

## 実装
surface.jsはPC/SPの手作業の稜線制御点、高さ場、非対称な荷重場、面との交点を担当。material.jsは変形後の法線、繊維・粗さ、左上の共通照明、琥珀反射とBのみの厚み依存透過を担当。renderer.jsは共有WebGL2メッシュ。preview.jsはPointer Events、指数応答、光の遅れ、復元、開発UIと資源解放を担当する。
G1写真から立体を自動復元せず、写真は比較とWebGL非対応時の静止代替だけに使用。膜の出力alphaはA/Bとも1。Bでは光学密度・稜線・繊維で減衰する背後の微光を加算する。物理的な材料測定や有限要素法ではない。

## 操作・比較
PCはポインター押下、SPはタップ／短い静止接触。SPは75ms保持後に通常荷重へ移る。指圧不使用。pan-y pinch-zoomを維持しtouchのpreventDefaultを呼ばない。縦移動、pointercancel、画面外、blur、複数接触で解除。
「同じ荷重を再生」は面UV(.64,.48)、目標荷重1、2.4秒。A/Bで形状・入力状態・復元を共有する。
比較資料はPC1440×900 / SP390×844、DPR1、Full。前／約1.6秒接触／ゼロ復元後の24画像。8録画は静止約0.6秒→接触2.4秒→復元約2.4秒。ブラウザ内の荷重再生を録画したもの。実際のフレーム時刻は比較JSON参照。ABの静定荷重と形状一致は別途検査。G1重ね量0〜100%は既存機能を維持。

## 負荷候補
Fullは256×192分割、49,601頂点・98,304三角形、986,632bytes。
Balancedは192×144分割、27,985頂点・55,296三角形、555,656bytes。
解像度、DPR上限、照明、材質、荷重は共通。標準Fullを維持し自動降格はしない。稜線細部に局所差がありBalancedは評価用候補。
静止・画面外・バックグラウンドでRAFを停止。PC DPR1.5 / SP1.25上限、buffer長辺PC2400 / SP1400上限。証拠取得のためpreserveDrawingBuffer使用。本編採用時には再評価する。
AではB専用の厚み・背後光計算を省略。荷重場の重複評価も削減。
性能JSONのGPU timer queryは自動Edge上の描画のみ、disjoint値は除外。低性能実機FPS、発熱、電池の結果とは扱わない。

## 資源と代替
WebGL2非対応・初期化失敗・context loss時はG1静止見本。復旧時は資源を再作成。pagehideでGPU資源解放、BFCache復帰時に再構築。destroyでRAF、timer、event、observer、buffer、shader、program、VAOを解放する。

## 検証と限界
既存verify.cjsの31項目維持。比較48項目と補足9項目を追加。結果JSONはreport.htmlから参照。
Originalと前回版はPC/SP静止／接触A/B画素一致。Readable100ms付近は面が動きglow0。A/B形状一致と接触前／ゼロ復元後の画素一致を確認。
物理iPhone／Android、実機低輝度・屋外、Safariバー伸縮、低性能GPU、長時間の発熱・電池・GPUメモリは未検証。低輝度表示はbrightness(.55)模擬。
Readableも控えめな光であり、指による遮蔽・低輝度ではA/B差が伝わりにくい可能性がある。G1の細部は簡略化。強い沈みや狭い範囲では法線やメッシュ段差が目立つ場合がある。
