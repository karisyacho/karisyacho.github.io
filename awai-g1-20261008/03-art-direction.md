# AWAI G1 — アートディレクションと静止キーフレーム

制作日：2026-10-08。G0承認後のG1提出案。PC5枚・スマホ5枚を制作。本人の美術承認待ち。G2、接触、染色アニメーション、スクロール演出、本編統合は未着手。旧公開ページは変更しない。

確認用ページ：[5場面の比較プレビュー](https://karisyacho.github.io/awai-g1-20261008/g1-keyframes/)。各画像から文字付きの単独キーフレームを開ける。

## 1. 美術の核

一本の面が、正体不明の黒から、金属・布・藍を経て白い紙になる。各作品のWeb画面ではなく、素材に近づいた撮影距離で世界をつなぐ。

共通する形は、左上から右下へ伸びる低い張力の稜線。光も同じ側から来る。材質は変わっても、見ている境界の連続性を残す。中央の主役や説明の繰り返しを避け、場面ごとに空白の位置、面の向き、視線の流れを変える。

S0とS4だけは同じ画像の構図を参照する。暗い膜のPC/SPをそれぞれ編集対象にして、対応する白い紙を作った。PCからスマホへの切り抜きは行っていない。

## 2. 五つの静止構図

| 場面 | PC構図 | スマホ構図 | 判断してほしい点 |
|---|---|---|---|
| S0 BLACK MEMBRANE | 全面の黒い膜。斜めの稜線を右へ流し、左下に深い黒。小さな「あわい」は左上寄り | 上部の黒い余白を増やし、稜線が中央から右下へ下る。文字位置と17px基準の大きさを独立設定 | 何かの表面として見え、紙とまだ分からないか。黒が無表示に見えないか |
| S1 SUKETO | 下半分に豆と金属。トレイの弧と細い蒸気、上半分に黒。タイトルは右上 | 金属の弧を右から入れ、蒸気を縦方向に伸ばす。豆は右下、左上にタイトル | 暖かさがカフェの自然素材感ではなく、焙煎の熱と機械の質感として見えるか |
| S2 KASANE | 厚い布・透ける布・背面布の3面。斜めの前景と縦の後景。左下は黒い余白 | 3面の段差を縦へ伸ばす。前景の左、中間の中央、後景の右。タイトルは右上 | 布ごとの重さと前後関係を読み分けられるか。動かす層として構図が成立するか |
| S3 AIMA | グラファイト色の未染の面が左、藍が右。同一布の織り目に沿う不均一な染色境界 | 上側に未染の余地、右下に藍。染色の方向を斜め上へ変える。文字は左上 | 白紙を先に見せず、染色の余地と藍の深さが伝わるか |
| S4 WHITE PAPER | S0と同じ斜めの稜線を白い紙に残す。左下寄りに一行の言葉と相談の文字 | S0-SPの稜線を参照。下方の左に二行の言葉と相談の文字。PCとは別の文字サイズ | 冒頭と同じ面だと感じられるか。初めて現れる白に終幕の強さがあるか |

S3の未染布は白ではなく暗いグラファイト。本案では最初の大きな白い面をS4まで出さない。S1〜S3の作品名は小さく置き、札やカードの枠は作らない。場面番号・解説・寸法は確認ページの外側だけに置く。

## 3. 色・光のルール

| 役割 | 基準色 | 使用ルール |
|---|---|---|
| 空間の黒 | `#090A0C` | S0〜S3の共通基底。全面を単色黒に潰さず、素材の陰影を残す |
| 布・膜の明部 | `#28292D` | 微かな面の違い。発光する輪郭や縁取りにはしない |
| 焙煎の琥珀 | `#AD6B35` | S1の豆・金属に局所的に置く。全面をオレンジにしない |
| 深い藍 | `#132B48` | S3でのみ色の主役。鮮やかな青や発光表現にしない |
| 終幕の紙 | `#ECEDEF` | 大きな白い面はS4で初出。生成りの標準背景として扱わない |
| 暗い場面の文字 | `#BFC0C4` | 黒との読みやすさを確保する抑制した灰白 |
| 白紙の文字 | `#2C2D31` | 黒に近い墨色。箱型CTAや広告的な強調をしない |

上記はデザイン基準で、写真の全ピクセルをこの色に固定する値ではない。生成画像には局所的な反射・陰影・繊維のハイライトがある。

光源は左上の大きな柔らかい面光源を想定し、右下へ斜めに落とす。S1だけ光の色温度を暖かくし、方向は維持。S4は同じ方向の拡散光へ変わる。粒子、光彩、レンズフレア、発光する縁、3D球体は加えていない。

## 4. タイポグラフィと配置

日本語は `Yu Mincho → Hiragino Mincho ProN → serif`、欧文作品名は `Times New Roman → serif`。確認用解説は `Yu Gothic → system-ui`。端末搭載書体の参照のみで、フォントファイルの抽出や再配布はしていない。Webフォントの最終採用は未決定。端末により字形が異なる。

| 表示 | PC基準1440px幅 | スマホ基準390px幅 |
|---|---|---|
| S0「あわい」 | 20px、左9%・上13%、字間0.2em | 17px、左9%・上13% |
| S1「助任珈琲豆店」 | 17px、右9%・上18% | 14px、左10%・上17% |
| S2「KASANE」 | 18px、左9%・上76%、字間0.18em | 16px、右10%・上8% |
| S3「AIMA」 | 18px、左9%・上12%、字間0.18em | 16px、左10%・上10% |
| S4の言葉 | 25px、左12%・上66%、一行 | 19px、左10%・上67%、二行、行高1.9 |
| S4「話してみる」 | 18px、言葉の下32px | 16px、言葉の下24px |

S4の正確な文言は「ここに、あなたの店の話が入ります。」「話してみる」。スマホでは「ここに、あなたの／店の話が入ります。」で改行する。文字は画像に焼き込まず静的HTMLに置き、各構図の縮尺に合わせる。今回は相談文字の見た目だけで、問い合わせ送信や外部サービスへの遷移は実装しない。

## 6. 場面間の視覚的な接続方針

| 接続 | 引き継ぐもの | 変わるもの |
|---|---|---|
| S0 → S1 | 左上の光、黒の空間、斜めの稜線の方向 | 不明な面の微光を、金属の弧と豆の局所的な琥珀へ受け渡す |
| S1 → S2 | 金属の弧の視線の流れと黒い余白 | 琥珀の面積を減らし、硬い反射を布の縁・柔らかい陰影へ渡す |
| S2 → S3 | 布の織り目、斜めの張力、背面の面 | 重なる3面から一枚の面へ視点を寄せ、右側/右下を藍が占める |
| S3 → S4 | 面の斜めの稜線と光源方向 | 染まった世界を奥へ退かせ、境界面を初めて白として見せる。染色結果をリセットして白に戻す演出とは分ける |

これは美術上の受け渡し案で、モーフィング、透過、タイムライン等の実装方式を決めたものではない。単純なフェードの繰り返しで接続を済ませない。接触あり/なしの合流方法はG2/G3へ持ち越す。

## 7. 制約と美術上の未解決事項

1. **S0の材質の読み。** 現画像の細かな凹凸は皮革に見える可能性がある。紙と分からない曖昧さは意図だが、膜としての張力と硬さの最終調整は承認事項。
2. **S0/S4の同一性。** 参照編集で稜線を残したが、物理的に同一の面を保証する3D/変位データはない。白紙側の起伏をどこまで残すかを静止画で確認する。
3. **S2の独立性。** 3層は視覚的に分かれるが、この画像自体は1枚の合成。層ごとのalpha、隠れた部分、前後の陰影、PC/SP対応は未制作。G2へ進む前提に独立素材が必要。
4. **S3の染色。** 既存12染点の円距離＋noise方式をそのまま使わず、布目に沿う浸透を目指す。今回の染色境界も静止見本であり、未染/染色の対応マスクや残留処理はない。未染の灰が明るすぎないか、藍の量を本人に確認する。
5. **解像度と画面比率。** PC背景は約7:4、SPは約4:7（S4-SPのみ高さ1px差）。生成結果の全景を保った比較用の画面で、PC1440px/スマホ390px幅を文字設計基準とする。390×844等の物理画面全体をどう埋めるかは未確定。現案を機械的にcover cropして実装しない。
6. **黒と文字の実機視認性。** 物理iPhone/Android、屋外・低輝度での黒階調と小文字は未確認。今回のブラウザ表示確認と区別する。
7. **書体。** OS書体のため端末差あり。最終書体を固定する場合はWeb配信条件と日本語フォントの容量を確認する。
8. **素材の実在性。** S1の豆・金属・蒸気は架空の生成見本。実際の助任素材としての正確性、焙煎機の機構は確認していない。納品実写と表示しない。
