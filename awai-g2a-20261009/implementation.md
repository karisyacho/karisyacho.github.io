# AWAI G2-A — 黒い膜の単体プロトタイプ

2026-10-09。G1/G1.5承認後のS0のみ。A（不透明な反射）／B（光学密度の変化による弱い透過）を共有実装で比較する。KASANE、AIMA、場面転換、映画スクロール、本編への組込みは未着手。

## 動作と構造

- `surface.js`：PC/SP別の手作業の5制御点、Catmull–Rom稜線、非対称な高さ場、周縁固定帯、稜線方向の荷重、CPU側の面との交点。
- `renderer.js`：WebGL2、49,601頂点／98,304三角形の面。位置と法線を高さ場から更新。独立画像の円形変形は行わない。
- `material.js`：手続き的繊維／粗さ、左上の共通光、陰影、遅れる琥珀反射。A/Bで同じ頂点・照明・荷重・復元を共有し、Bの透過放射だけを追加。
- `preview.js`：Pointer Events、短タップ→保持による荷重、指数応答／復元、縦操作の解除、キーボード、静止代替、context loss復旧と破棄。
- `preview.css`：画面は`100svh`。開発UIは面の外に配置。比率が変わってもG1参照画像をcoverで切り取らず、幅を保った参照座標へ実際の面を延長。

PCは近づくとごく小さな予備応答、押下で荷重。スマホは接触直後に弱い荷重、75ms保持後に通常荷重を目指す。指圧は使用しない。接触位置は変形後の正射影面のx/yを6回の反復で逆算する。物理的な有限要素法や実測素材の光学シミュレーションではない。

## 調整項目

| 項目 | 初期値 | 調整域 |
|---|---:|---:|
| 沈み | 基準短辺1.1% | 0.2–2.5% |
| 稜線に沿う影響範囲 | 基準高17% | 8–35% |
| 稜線方向／横断方向 | 2.8 : 1 | 1.5–5.0 |
| 応答係数 | 11 / 秒 | 3–24 |
| 復元係数 | 4.3 / 秒 | 1.5–12 |
| 琥珀反射 | 0.13 | 0–0.5 |
| Bの透過係数 | 0.12 | 0–0.5 |

影響範囲は厳密な境界ではなく減衰関数の尺度。荷重場は稜線に沿う超楕円・繊維方向のむら・固定帯の積。稜線方向の連続性を保ち、円形窓・穴・破れは作らない。Aは出力alpha=1。Bもalpha=1で合成するが、表面の厚みで減衰した背後の微光を放射項として足す。光学的な透過の近似であり、背景写真を露出させる透明窓ではない。

UIの「同じ荷重を再生」はUV(0.58,0.48)を2.4秒押す。開始時に荷重と遅れた反射をゼロへ揃える。A/B切替は面形状と入力状態を変更しない。G1重ね量は0%（実装）／50%（比較）／100%（参照）で確認できる。

## 負荷と代替

静止時はRAFを停止。画面外・バックグラウンドでは更新を停止。DPR上限はPC1.5/SP1.25、描画buffer長辺上限はPC2400/SP1400。頂点・index bufferは986,632bytes。画面bufferやブラウザ内部のGPU資源は別。証拠の画素読出しのため`preserveDrawingBuffer`を使用しており、本編採用時には負荷を再評価する。

WebGL2非対応・初期化失敗・context lossではG1の静止見本を表示し、操作可能とは表示しない。復旧時はGPU資源を再作成。pagehideで描画資源を解放し、BFCache復帰時は再作成。destroyでRAF・timer・event・observer・buffer・shader・program・VAOを解放する。

入力のブラウザ共存は[MDN touch-action](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/touch-action)、復旧試験は[WEBGL_lose_context](https://developer.mozilla.org/en-US/docs/Web/API/WEBGL_lose_context)を参照。`pan-y pinch-zoom`を維持し、touchに`preventDefault`を呼ばない。

## 素材と公開の境界

G1のS0 PC/SPのWebPは原本と同じ内容を比較・静止代替としてコピー。生成仮素材であり本番採用の許諾確認とは別。材質と形状は今回の自前手続き表現。外部フォント・写真・動画・ライブラリを描画に使用しない。既存の公開本編と設定を変更せず、新規`awai-g2a-20261009/`だけで公開する。

## 既知の問題と未確認

1. 稜線・黒の余白・光の方向はG1を基準としたが、写真と同一ではない。繊維は手続き的で均質に見える部分があり、稜線の細部や左側の起伏は簡略化している。G1との重ね比較で評価する。
2. 高い沈み量／狭い影響範囲では面の法線変化が目立ち、稜線付近に細かなメッシュ由来の段差が残る可能性がある。初期値は控えめ。
3. A/B差は意図的に弱い。低輝度や指で隠れる位置では判別しにくい。透過量は開発UIで比較できるが、初期値の美術採否は本人評価待ち。
4. 「低輝度」チェックは画面にbrightness(.55)を適用するだけ。物理iPhone／Androidの通常・低輝度・明るい場所、実機Safariのバー伸縮、長時間の発熱／電池、低性能GPU、GPUメモリ／GPU時間は未確認。
5. 高さ場と指数復元は弾性の演出モデル。実際の膜の力学・厚み・散乱を再現したとの主張はしない。

検証結果と証拠は `report.html`／`evidence/test-results.json`。G2-Aの提出後は本人の評価を待ち、次の場面へ自動で進まない。
