# あわい 全編インタラクティブ通し仮版

2026-10-11。目的は5場面と4か所の介入を最後まで体験して、本人が弱い場所を選ぶこと。

## 構造と入力

1ページ、sticky舞台1枚、表示Canvas 2D 1枚。文字はDOM。通常の縦スクロール1240vhで時間を進め、S0薄まり、S2層移動、S3藍の保持、S4空白への薄まりを介入とする。S1とつなぎに入力反応を加えていない。

S0の珈琲はS1と同じ画像。同一座標のまま膜が薄くなり、S1内だけ1.00→1.04で寄る。S2の最奥はS3と同じ黒布。S3はp>=.92で藍のマスクが全面を覆う。S4では同じ薄まりの形で紙の密度が下がり、白だけが見える。

舞台の高さは100lvh。iOSのアドレスバーが伸び縮みしても高さと時間軸が変わらないため選択。回転やウィンドウサイズの変更はResizeObserverで追従する。画面が隠れた時はRAFを停止。touch-actionはpan-y pinch-zoomで、縦スクロールとブラウザのピンチを許可。

reduced-motionは5枚の静止画をHTMLで順に表示。JS無効でも「あわい」、3作品名、コピー、相談リンクが読める。相談先は現ポートフォリオのInstagramと一致させた。新フォームは作っていない。

## 仮の所

- KASANE：権利確認済みのG0布を明度alphaで抜いた3層。G1の実際の透け布の外形・重量を再現した本番素材ではない。本人評価後に独立する布の外形と隠れた部分を持つ素材へ置換する。
- AIMA：黒版と藍版は同じG1画素なので皺は一致。ただし元G1は染色途中の構図で、マスク全面露出でもグラファイト領域が残る。必要なら本人承認後、同一画素の完全藍版へ色処理する。
- つなぎ：共有する斜めの軸の密度/輝度マスクで接続。写真の金属の弧と布の稜線では、曲率・ハイライト幅・位置の完全一致までは追い込んでいない。seam-23の最奥黒布は同じ座標。
- スマホでの膜発見の強さ、暗部の見え方、触ることへの気づきは本人の実機評価待ち。個別演出の研究は行わない。

## 承認値からの変更

hold260ms / gesture8px / release1200ms / thinning2200ms / spread2600ms / response95ms / DPR PC1.5・SP1は保持。

- 最初の弱反応：直後の次の描画（100ms以内の設計）に最大15%を出す。縦移動で取り消した跡は300msで戻す。
- PCは押した時から薄まる。乗せただけでは最大8%。
- transmission .46→.64。黒い膜の向こうの珈琲を読めるようにする。1.0の穴にはしない。
- 楕円を稜線方向へ回転、長軸1.30/短軸.56。S0/S4同じ形。写真の繊維明度で輪郭を変調。
- タッチ中心を半径の.4倍、指より上へ。跡は最大6個、各1200msで戻る。
- 琥珀にじみ.15、事前blur sigma14。ctx.filterは使わない。
- 描画が重い場合はマスク160→110列、跡6→3、にじみ無効、DPR1の順で質を下げる。fpsの固定制限は入れない。

evidence/lighthouse-mobile.jsonはLighthouseのスマホ設定でのローカル計測。INP auditは存在しなかったため、INPを0や推測値で埋めない。evidence/input-performance.jsonのlabInteractionP98MsはChromeの実タッチEventTiming実験値で、フィールドINPや実機値ではない。

実機iPhone/Android、実機Safariのアドレスバー、屋外の暗部視認性は未確認。自動確認は美術や触感の評価ではない。
