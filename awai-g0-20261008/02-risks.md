## 2. PC・スマホの制約

上表のKASANE/AIMAは紙試作本編を指す。作品元サイトには別のWebGL実装がある：AIMAの時刻付き12染点、KASANEの一枚布。技術参考として再利用候補だが、複数独立層・持続maskへの適合と性能は未検証（詳細は00-audit.md）。

- **入力競合：** 現行は`touch-action:pan-y pinch-zoom`、長押し260ms、縦移動解除。新布のdrag/染色にもその値が適切とは限らない。縦scrollが進行、touchが介入という両立をG2で検証。スクロール禁止や強制ジャンプに置き換えない。
- **スマホの見え方：** 現行は`100svh`、DPR PC1.5/スマホ1等。黒い布の層は明るい屋外/低輝度で潰れる可能性がある（新制作への懸念、未測定）。指に隠れる接点、縦横変更、safe-area、Safariのバー伸縮も物理端末で確認。
- **動画：** OpeningSceneはgesture内の再生要求とposter fallbackを持つ。本編FilmStage自体にはvideoがなく、`verify-film.cjs`でもvideo count 0を検査。場面見本の動画を本編実装済みと誤認しない。新動画は無音/inline/再生拒否/バックグラウンド停止、posterだけでも話が成立することを検証。
- **描画：** 現行DPR制限やcleanupは候補だが、複数alpha布と残留染色のGPU/Canvas負荷は未測定。画面サイズ×DPRによりbuffer容量が変わる。G2で低性能端末を含む計測後にCanvas/WebGL/CSSの方式をG3で決める。
- **アクセシビリティ：** 現行のkeyboard/reduced motion/JSなしの情報到達思想を残す。新作でも無操作の自動進行ではなくscrollのみで理解でき、操作誘導がキーボードでも成立する必要がある。代替表示の構成はG1/G3で決定。
- **尺：** 現行2060vhは秒数を保証しない。自由scrollでは60〜90秒を全員に強制保証できない。推奨鑑賞のテンポとして扱うか、最低保持をどこに許すかG1/G3で明文化。操作なし/ありを終端で合流させる状態設計、逆scroll/再訪時の染色保存期間も未決定。

## 3. GitHub Pages公開制約

確認した現行設定はlegacy / main / root、`.nojekyll`あり。Next静的exportを公開できる構成だが、動的サーバ処理はこの配信構成にない。相談は現在LINE/Instagram外部リンクで、サーバ側フォーム送信は確認できない。

`/awai-paper`に固定されたmedia/CSS URLは本番pathが変わると見直しが必要。`images.unoptimized:true`なのでNextの配信時自動画像最適化に頼れず、派生画像の寸法/容量/縦横cropを事前に用意する。動画scrubは配信のRange対応とcodec/keyframeを実測する。現行公開方法を新作公開先として自動決定しない。

監査資料の共有は既存承認済み公開repoに新規の資料専用フォルダを追加する。既存本編/ルート/公開設定は触らない。これはG1制作開始を意味しない。

## 4. 素材ライセンスの判断

台帳で「出典サイト名がある」「生成した」「ユーザー提供」の記録と、商用利用許諾確認を分ける。URLが作品サイトだけの場合は写真素材の原配布URLとは扱わない。第三者の人物/建物/商標の権利、モデルの許諾、生成サービス/モデル条件は配布ライセンスだけで一括解決したと判断しない。

採用には原配布URLとライセンス種別・確認日、加工/再配布条件の証跡が必要。Free/Restrictedが分かれる配布元は個別素材の種別を確認。確認できない素材は保留とする。フォントも端末参照とWebフォント再配布を区別する。

## 5. 最初のプロトタイプ前に必要な確認

1. **G0承認→G1承認。** 5場面の静止構図、黒/琥珀/藍/白の連続性、素材の同一性を先に確定。G0から直接本編を実装しない。
2. **採用素材の許諾。** 膜・黒布・藍布の元素材と加工権限。助任の焙煎素材、既存動画/生成素材の利用条件を個別確認。
3. **必要派生素材。** KASANEの独立alpha布（隠れた領域/陰影の分離）、AIMAの未染/染色対応画像・布目・浸透mask、膜の変形用height/normal等が必要かを方式と合わせて検討。G0では制作しない。
4. **操作と合流。** 自由接触/重要操作への誘導、無操作時の展開、復元/残留、シーン離脱・逆scroll・再訪の仕様。S4では触れても奥がないことを表現。
5. **試験端末と合格条件。** iPhone Safari/Android/PC、対象の低性能端末、動作低減/keyboard/再生拒否。触感・黒の視認性・描画負荷をG2で比較できる条件を定める。

## 6. A / B / C

- **A 再利用すべきもの：** 作品情報と見本/依頼区分、確認済み元素材・変換履歴、入力競合解除/動画停止/静的代替/cleanupの小さな処理、連絡情報、検証記録。
- **B 破棄すべきもの：** 新本編としての旧20場面/7作品順列、白紙常設、完成Webのreveal、丸い透過窓、立体道具・粒子、写真カットを布の介入とする構造。G0では現物を削除しない。
- **C 事前確認：** G0/G1承認、採用素材の利用条件、独立布/染色maskの不足、操作と合流・残留仕様、端末/性能の評価条件。
