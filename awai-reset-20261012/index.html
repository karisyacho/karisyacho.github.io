THE DIRECTION

あわいの仕事を、
立体で見せる。

このサイトの主役は、あわいがつくるWebと紙。入場した直後に仕事内容を伝え、クリックするごとに制作物へ近づく構成です。制作物を読む場面では正面へ戻し、文字や写真が見えるところで止まります。

  1. 00 / ENTER

    AWAIの入口

    AWAIを表示して、最初は少し待つ。カーソルへ反応し、クリック／Enter、スマホはタップで入場。

  2. 01 / AWAI

    何をつくる人か

    Webサイト、メニュー表、チラシ。仕事内容を大きく示し、制作物を一つ見せる。

  3. 02 / WORK

    制作物を見る

    Webの画面や紙面を、動きながら近くへ。正面で止まり、見た人が内容を読める時間をつくる。見本と実案件を明記する。

  4. 03 / TALK

    自分のお店の相談へ

    つくれるものと進め方を伝え、相談へつなぐ。途中の場面からも相談できる。

このページは、入口後の見た目と構成を確かめる案です。自律する3Dの動きや、スマホでの描画性能を確認する本実装は、この方向を決めた後に行います。

AIMAは既存の制作見本です。実在する施設の制作実績としては掲載していません。
