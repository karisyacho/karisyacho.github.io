# 動画を作る前に、見る理由を決める

2026年10月19日調査。社長（仮）Day26の指摘を受け、公式説明、制作者本人の解説・対談、日本の14組への取材、運用データを照合した。本文確認した採用資料は30件。記事や対談の文字起こしを読む調査で、新しい動画30本を視聴したという意味ではない。

**今回の問題は、「何を作ったか」は伝えても、「この人の何が気になって、最後まで見たくなるのか」を決めていなかったこと。** 見せ方を整える前に、誰に何を伝え、見た後にどう思ってほしいかを決める必要がある。

このページは調査結果と制作方法の見直し。Day26の新しい台本・絵コンテ・修正版は、まだ作っていない。

## 1. 複数の人の意見から分かったこと

### 視聴者を「誰でも」にしない

Colin & Samirは具体的な一人を想定し、その人が友人に一文で紹介できる題材かを考える。Film BoothのEd Lawrenceは、作者が教えたい技術と、視聴者が気にする結果の接続を重視する。どちらも「作業したから報告する」だけでは足りないという観点に使える。ただし、主に長尺YouTubeの経験談である。[Colin & Samir](https://www.musicbed.com/articles/filmmaking/youtube/the-biggest-mistake-filmmakers-make-with-colin-and-samir/)、[Ed Lawrence](https://creatorscience.com/podcast/ed-lawrence/)

社長（仮）には、母の会社を継ぐ過程を見守る人、制作技術に関心がある人、仕事を依頼する可能性がある人という異なる見方があり得る。これは過去の投稿からの整理で、実際の視聴者構成を測定した結果ではない。全員へ同時に話そうとせず、今回の一本で主に誰へ届けるのかを選ぶ。

### 「分かる」と「見たい」は別

Jay Clouseは、発信の前提を理解できること、関心を持てること、他と違うことを分けている。用途を説明して意味が通っても、それだけでは魅力にならない。今回、サイトの説明を足して解けたのは文脈不足で、見る動機の弱さは残った。[Designing Your Premise](https://creatorscience.com/premise/)

セカイ監督は、出演者を知らなくても気になる設定を先に考える。関ミナティは、自分が実際に行ける店に興味を持った経験からコンビニを題材にした。入口の言葉だけでなく、題材と見る人の接点を探す発想である。[セカイ監督の対談](https://note.com/sekaikantoku/n/n1514d0c1d438)、[関ミナティの取材](https://wpb.shueisha.co.jp/news/technology/20240904-124393/)

### フックで約束したものを、本編で渡す

Jenny Hoyosは驚きから関心、満足へつなぐ短い物語を説明する。脚本家George Blackmanは最後の答えと、そこへ進む途中の小さな答えを設計する。使える共通点は「疑問を置いたら、進展と答えを見せる」こと。最後まで隠し続けるだけではない。[JennyとTodd Sherman](https://blog.youtube/creator-and-artist-stories/youtube-shorts-deep-dive/)、[George Blackman](https://creatorscience.com/podcast/george-blackman/)

ただし全動画に失敗や対立が必要とは言えない。Toddは短い印象的な瞬間も例に挙げる。美しさ、笑い、共感、実用、発見でも成立し得る。実際にない苦労や期限を足すのではなく、この一本が何を見せ切る作品なのかを選ぶ。

### 再生を集めた後に、何が残るか

Jayは注目を集める活動と信頼を育てる活動を区別する。Edは、広く受けた一本が通常回とは違う層を集めてしまった経験も話す。再生だけを狙ってDayの路線を変えると、次回を見てほしい相手とずれる可能性がある。[注目と信頼](https://creatorscience.com/attention-vs-trust/)、[Edの失敗談](https://creatorscience.com/podcast/ed-lawrence/)

今回なら「すごい映像」への反応と、「この人の事業の続きが気になる」は同じではない。どちらを主に残したいかを制作前に言葉にする。営業目的の回でも、問い合わせが増えたと確認する前に効果を語らない。

## 2. 「最初の何秒」は、何の根拠なのか

| 数字・助言 | 原典での意味 | 今回の扱い |
| --- | --- | --- |
| 最初の1秒 | Jenny HoyosがShorts対談で語る経験則 | 1コマ目から見る動機を作る目安。YouTubeの判定仕様ではない |
| 最初の2秒 | 日本の取材では音楽・金融など各人の型として登場 | 題材と対象によって役割が違う。全分野に強制しない |
| 最初の3秒に価値 | TikTokの広告向け助言 | 何の話で、見る価値は何かを早く示す参考 |
| 最初の6秒のフック | TikTokの広告向け助言・広告想起の研究紹介 | 自然投稿の配信基準ではない。6秒まで説明を待つ意味でもない |
| 3秒が全て | 熊田ゆうまの実務解説の強い表現 | 注意を早く取る発想は参考。比較実験の結論とは扱わない |

出典：[YouTube公式対談紹介](https://blog.youtube/creator-and-artist-stories/youtube-shorts-deep-dive/)、[TikTok広告の制作指針](https://ads-useast2a.tiktok.com/resources/help/article/creative-best-practices?lang=en)、[Creative Codes](https://ads.tiktok.com/business/library/TikTok_CreativeCodes_May2023.pdf)、[熊田ゆうま](https://do-gaku.com/column/short-video-scenario)、[TikTok for Businessの14組取材](https://ads.tiktok.com/business/ja/blog/creator-whitepaper-2024?redirected=1)

「6秒で広告想起への影響の90％」を「視聴者の90％が6秒で離脱」に読み替えてはいけない。対象と測ったものが違う。同様に、維持率や見続けた割合に、全媒体共通の公式合格点は確認できなかった。

## 3. 冒頭から最後まで、どう確認するか

以下は調査を踏まえて採る制作上の目安で、媒体公式の時間割ではない。秒数を埋めることより、見る人の理解と期待が進むことを優先する。

| 見直す位置 | その時点で伝えるもの | 映像と言葉の確認 |
| --- | --- | --- |
| 0〜1秒 | 主役と、気になる点の入口 | ロゴや前置きから始めず、具体物・行為・変化を見せる。数字を載せるなら何の数字かも分かるか |
| 1〜3秒 | 何の話か／なぜ自分が見るのか | 初見でも分かる最小限の状況と、確かめたくなる点をつなぐ。タイトルの読み上げだけで使い切らない |
| 3〜6秒 | 冒頭の約束へ進む最初の証拠 | 背景説明へ戻りすぎず、実物・試行・違い・本人の判断を一つ見せる |
| その後 | 新しい情報・変化・感情 | 各場面で理解が進むか、予想が変わるか、気持ちが動くか。字幕を替えただけの同じ説明は減らす |
| 終わり | この一本で分かったこと | 冒頭の期待を回収する。次回予告や質問は、その結果から自然につながる場合に置く |

音を消しても「何を見ているか」が分かるか、音声だけでも「何の話か」が通るかを別々に確認する。ただし全情報を両方へ重複させる必要はない。映像で示せる変化に長い説明を重ねず、映像だけでは分からない理由や本人の思いを言葉で補う。

「完成を先に全部見せる」と「最後まで隠す」の二択でもない。入口で結果の一部を示し、過程や判断を知りたくさせる方法もある。何を先に渡し、何を本編の答えにするかを決める。

## 4. 内容の密度は、情報量やカット数で測らない

ここでいう密度は、見ている時間に対して、受け取れる発見・感情・変化・証拠があること。早口、テロップ増量、意味のない切り替えでは代用しない。これは調査からの制作判断で、科学的な採点式ではない。

台本と絵コンテの各場面に、「これを見た人は何を新しく知る・感じるか」を一行で付ける。同じ答えが続く場面はまとめる。必要な理解が抜ける場面は補う。短くするために主語やつながりを省き、意味不明になることも避ける。

活動記録で残す価値になり得るのは、出来事そのものに加えて、本人がどこに迷い、何を選び、何が分かったか。ただし毎回それを無理にドラマにする必要はない。出来事の中に見る価値が見つからなければ、その作業単独で一本を成立させる前提を見直す。

Wistiaも、示して証明する冒頭と、中盤の離脱の理由を分ける。必要な答えを得て満足して離れる場合もあるため、最後まで残る人の割合だけを最適化しない。[Understanding Audience Retention](https://wistia.com/blog/understanding-audience-retention)

## 6. Day26をこの基準で見直すと

| 観点 | 現在の動画で起きていること |
| --- | --- |
| 誰に | 制作に関心がある人なのか、事業の過程を見守る人なのか、主な相手が曖昧 |
| 何を伝える | 480枚から16秒のガラスを作った、という事実が中心 |
| どう思ってほしいか | 「手間がかかった」以上の受け取り方を定めていない |
| 続きを見る理由 | 冒頭の数字の後が用途説明になり、知りたい結果が育たない |
| 本編の進展 | 動く完成物が冒頭にもあり、後半の回転だけでは新しい答えが弱い |
| 締め | スマホ対応という作業予定を予告し、今回の意味を補えていない |

480枚は素材の仕様でもある。枚数を出すだけでは、通常より難しい挑戦や視聴者にとっての価値を証明しない。必要だったのは、この作業が本人の何の判断や変化につながったのかを、事実から確かめることだった。

前の手本比較も見直す。5本のうち3本は同じ作者で、時間制限のある制作挑戦が多い。画面や工程は参考になっても、活動記録の見る動機まで同じとは限らない。「難しさはあえて違う」と記録して検査を通しても、それに代わる面白さがあるとは言えなかった。**形式の確認に通ることと、内容が面白いことを混同した。**

この診断は台本・映像・本人の感想からの内容評価で、配信不振の原因を統計的に確定したものではない。最新の非公開指標は引き続き未取得である。

## 7. 次に作る前に埋める項目

1. **誰に**：主な視聴者は誰か。その人は何を既に知り、何を気にしているか。
2. **何を伝えるか**：今日の活動から、今回ひとつだけ持ち帰ってもらうことは何か。
3. **どう思ってほしいか**：発見、共感、驚き、信頼、応援など、狙う受け取り方を具体的に書く。
4. **なぜ見続けるか**：先に知りたい問い、変化、体験は何か。
5. **何を見せれば伝わるか**：それを裏づける本人の事実と、実際に使える映像は何か。
6. **どこで答えるか**：入口・途中・最後に何を渡すか。次回予告で今回の答えを代用しない。
7. **過去回と何が違うか**：題材だけでなく、悩み・判断・結論・問い・映像を照合する。

これは次の企画案ではなく、制作前の確認項目。先に短い内容メモで揃え、それから台本と絵コンテへ進む。語句を強くしただけ、画面を動かしただけで、内容の面白さが増えたと扱わない。

## 8. 公開後は、何を見て直すか

YouTubeは視聴選択、視聴時間、平均再生率、評価や満足を挙げ、題材の需要・競合・季節性も説明する。2025年3月31日以後のShorts Viewsは再生開始やリプレイも数えるため、公開再生数だけでは内容への満足は分からない。[推薦の公式説明](https://support.google.com/youtube/answer/11914225?co=YOUTUBE._YTVideoType%3Dshorts&hl=en-GB)、[Viewsの変更](https://support.google.com/youtube/answer/10059070/get-started-with-youtube-shorts?hl=en-GB)

| 確認したいこと | 見る材料 | 判断の注意 |
| --- | --- | --- |
| 入口で選ばれたか | 見続けた／スワイプ、冒頭の離脱 | 弱ければ主役・文脈・見る動機を再確認 |
| 途中で期待が続いたか | 維持曲線と実際の台詞・映像の対応 | 落ちた秒の前後を確認。離脱を一つの理由に決めつけない |
| 何が残ったか | コメントの内容、共有、保存、フォローなど利用可能な反応 | 数より、狙った受け取り方との一致を読む |
| Dayの続きが見られたか | 次回の視聴、戻る視聴者、フォロー後の反応 | 一本だけの大きな再生と分けて確認 |
| 事業へつながったか | プロフィール遷移、サイト訪問、実際の問い合わせ | 媒体の再生数を売上の代わりにしない |

同じ媒体・近い尺・近い題材で、公開後の経過時間もそろえて比べる。変更前に主な仮説を一つ決める。別投稿同士は視聴者や配信条件が変わるので、結果差をその変更の因果効果と断定しない。

InstagramのTrial Reelsは非フォロワーの反応を試す公式手段だが、統制されたA/B実験ではない。共有・保存の重みや万能閾値は今回の取得資料で確定できなかった。Metricoolの大規模調査も全世界の集計であり、このアカウントの合格値へ移さない。[Trial Reels](https://about.fb.com/news/2024/12/trial-reels-try-content-non-followers-first-see-what-perfoms-best/)、[Metricoolの調査方法](https://metricool.com/press-release-instagram-study-2026/)

## 9. 調査の範囲と限界

30資料は、同じ発言を紹介するページを30人の賛成と数えたものではない。公式の仕組みの説明、本人の経験談、広告の調査、自社の観察データを分けた。白書の14組も同じ取材企画で選ばれた人たちで、無作為な標本ではない。

新たな因果実験を行ったわけではなく、「この方法なら必ず伸びる」とは言えない。一方で、誰へ何を残すかも決めずに作る進め方は、この調査を待たずに改めるべきだった。
